# Diagrams

41 self-contained SVG diagrams that are embedded in the study-notes chapters at the
point where a picture explains the topic faster than prose.

Every file is plain SVG: shapes, paths and `<text>` only — **no external fonts, scripts,
CSS files or raster images** — so they render identically on GitHub, in VS Code, in an
offline viewer, or inside a sandboxed preview iframe with no network access.

## Regenerating / editing

The diagrams are generated by small Python scripts (standard library only, no
dependencies):

| File | What it builds |
|------|----------------|
| `_svgkit.py` | Shared helper kit: colour palette, `txt`, `box`, `line`, `arrow`, `elbow`, `note`, `tag`, `pill`, `title`, `wrap`, text-width estimator |
| `diagrams_networking.py` | 14 figures for chapters 01 (networking/security/cloud) |
| `diagrams_office_code.py` | 8 figures for chapters 02–03 (MS Office, pseudocode) |
| `diagrams_data_web.py` | 19 figures for chapters 04–06, 11–12 (DSA, DBMS, SQL, frontend) |
| `generate_all.py` | Driver — writes every `.svg` and runs a layout linter |

```bash
cd images
python generate_all.py
```

Success looks like: `41 diagrams written, 0 with layout warnings`.

The linter flags two classes of problem:

- **OUT OF BOUNDS** — a text label sticking out past the canvas edge.
- **OVERLAP** — two text labels colliding (the estimated boxes of any two labels
  overlapping by more than 5px in both axes).

If you add or edit a figure, grow the canvas height/width and re-space the rows until
the run is clean.

## Conventions

- Canvas: white background with a light `#e2e8f0` border, `30px` inner margin.
- Title at `y=34` (15px bold), optional subtitle at `y=53` (10.5px, muted).
- Long captions go through `wrap()` so they never run off the edge.
- Links in the markdown are relative to the repo root:
  `![alt](images/<name>.svg)`.
